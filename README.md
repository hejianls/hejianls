## About

My work focuses on large language models, natural language processing, multimodal content understanding, and computer vision. My experience includes retrieval-augmented generation (RAG), financial question answering, content understanding and recommendation, and visual recognition for retail applications.

## Research Interests

- Large language models, RAG, factuality, and model evaluation
- Natural language processing and hierarchical text classification
- Multimodal content understanding and recommendation
- Computer vision, object detection, tracking, and recognition
